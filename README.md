# CSV Check 运行说明

技术文档写作课程配套材料：用一条命令检查 CSV 表格的列名。

本仓库托管《CSV Check 1.0.0 运行说明》网页版，通过 GitHub Pages 发布。中英双版本，页面左侧为常驻目录。

中文页右上角有 `English →`，英文页有 `中文`，点击即可切换，两版章节结构一一对应。

## 内容说明

- 工具：`check.py`（随课程实践包 `01_写作练习` 提供，仅依赖 Python 标准库）
- 作用：读取 CSV，确认表头是否包含 `id`、`name`、`score` 三列，打印七行报告
- 文档含：任务全貌（六个要素、七步执行流程、三个理解要点）、运行前准备、三种结果（PASS / FAIL / ERROR）对照、退出码、故障排查
- 章节编号 00–07，另附 A（样例文件）、B（工具边界）
- 版式：宽屏左侧目录固定吸附、滚动自动高亮当前章节；窄屏折叠为抽屉
- 页面为单文件 HTML，三张终端截图以 base64 内嵌，无外部依赖
- 字体：中文楷体（Kaiti SC / 楷体），西文 Calibri，代码 Consolas（含跨平台回退）
