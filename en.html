Checking a Table's Column Names with One Command

CSV Check is a small tool that ships with the course pack. It reads a CSV file, confirms that the header contains the columns id, name and score, and prints a report. It never modifies your file.

01What this tool does

In one sentence: it checks whether the three required columns are present, then prints the verdict.

It does exactly four things. It reads a UTF-8 encoded CSV; takes the first line as the column names; checks whether the required columns are there; and counts the data rows. Bad scores, duplicates, out-of-range values — none of that concerns it. The last line of every report, PASS checks column names, not score values., is there to remind you of that, and most students skim past it.

Why the boundary comes first

A PASS means the column names are right, not that the data is right. If score contains the word "absent", the tool still reports PASS. State this boundary plainly in your documentation, or readers will misuse the result.

02Before you start: open a clean command window

Press Win + R, type cmd, press Enter. Then confirm Python is available:

> python --version

You should see a version string such as Python 3.13.15. If instead you get "not recognized as an internal or external command", or the Microsoft Store opens by itself, then Python is either missing or was installed without being added to PATH. Fix the installation first, then come back to this step.

Common trap

If you just installed Python, a command window that was already open will not see it. A window captures PATH the moment it starts, so software installed afterwards never shows up in it. Do not assume the installation failed — close the window and open a new one.

03Go to the folder and run it

The tool consists of two files: check.py is the entry point, and csvcheck is the package it imports. They must stay together, so change into the folder that holds them before running.

> cd /d "C:\Users\mwj06\Desktop\发给学生_技术文档写作\学生实践包\01_写作练习"

Quote the path when it contains spaces or non-ASCII characters; /d also allows switching drives.

> python check.py samples/students.csv

The first command only changes directory and prints nothing. The second follows the pattern python check.py TARGET_FILE; here it checks the sample file samples/students.csv.

Press Enter and you will see this:

Reading the seven lines

The report always has the same number of lines in the same order. Learn what each line asks, and you can spot the problem at a glance.

1
CSV Check 1.0.0

Tool and version. Quote it in a bug report.

2
File: samples/students.csv

The file actually read. If this is not what you meant, the argument is wrong.

3
Data rows: 3

Data rows below the header. The header itself is not counted.

4
Columns: id, name, score

Column names as read from the first line, in their original order.

5
Missing columns: none

Required columns that are absent. none means nothing is missing.

6
Result: PASS

The verdict. Only ever PASS or FAIL.

7
PASS checks column names, not score values.

A fixed reminder: PASS covers column names only, never the values. Always the last line.

Reading convention

Throughout this document, light blocks are commands you type and dark blocks are what appears on screen. Type the former, check your answer against the latter.

04Three possible outcomes

Every possible output falls into one of three categories. Telling them apart matters more than memorising the command.

PASS
The file was read and every required column is present.
FAIL
The file was read, but some columns are missing. Fix the header.
ERROR
The file could not be read at all. Replace it or fix the encoding.

ERRORThe file cannot be read

Start here, because this one least resembles a result — no PASS, no FAIL, just an error and a suggestion.

Two lines of output, yet they carry everything you need to diagnose the problem:

Output lineHow to read it
ERROR: File has no header.The first line is empty, so no column names could be read. Empty files and files containing only line breaks both behave this way.
Next step: use a readable UTF-8 file with a header row.The suggestion: use a readable UTF-8 file whose first row is a header.

In this case the program prints no Result: line. So the rule is: look for ERROR first, and only look at Result when there is none.

FAILThe file was read but a column is missing

This is the most common case. The file itself is fine; the header is one column short, or a name is misspelled.

> python check.py samples/missing-name.csv

The key is the contrast between lines 4 and 5:

4
Columns: id, score

The two columns the file actually has. The missing one is name.

5
Missing columns: name

Which of the three required names is absent. Add it to the header and you are done.

Whenever Missing columns is anything other than none, the final verdict is FAIL.

Two easy confusions

SymptomCause and fix
A .tsv file reports all three columns missing TSV uses tabs; the tool splits on commas only, so the whole header becomes one very long column name and matches nothing. Save the file as .csv.
The header clearly has Name but name is reported missing Column names are case-sensitive and whitespace-sensitive. name with a trailing space counts as missing too.
One-line distinction

ERROR means the file was never read; FAIL means it was read but is wrong. Fix the file itself in the first case, and the header in the second. They occur at different stages, and mixing them up sends you down the wrong path.

05Exit codes: the verdict for programs

Those lines on screen are for humans. Programs talk to each other through a single number — the exit code. To see the code from the run you just did:

> echo %ERRORLEVEL%

In PowerShell the equivalent is echo $LASTEXITCODE, with the same meaning.

CodeOutcomeMeaning
0PASSThe check passed. All columns are present.
1FAILThe file was read but required columns are missing.
2ERRORThe file could not be read (no header, not UTF-8, bad path, and so on).

This is what makes automation possible: a script never has to parse the text, it just looks at the number — 0 means success, anything non-zero means failure and should stop the run. Command-line tools follow this convention universally.

06Check your own table

Three ways, pick whichever suits you:

Option 1: drag and drop (easiest)

Type python check.py followed by a trailing space, then drag the CSV file from File Explorer into the window. The path is filled in for you; press Enter.

Option 2: type the full path

> python check.py "C:\Users\mwj06\Desktop\我的表.csv"

Paths containing spaces or non-ASCII characters must be wrapped in double quotes, or they are split into two arguments.

Option 3: put the file in this folder

Copy the CSV into 01_写作练习, then run python check.py YOUR_FILE.csv. No path worries.

Require different columns

The default is id name score, and you can override it:

> python check.py samples/students.csv --require id name

This requires only two columns. Add -h to list every option.

BWhat this tool does not do

  • It does not judge whether scores are sensible, duplicated or missing
  • It does not modify or repair your file — it only reads it
  • It does not accept Excel .xlsx; save as CSV first
  • It does not accept tab-separated .tsv
  • It does not handle files that are not UTF-8
